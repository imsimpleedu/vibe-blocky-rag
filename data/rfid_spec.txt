# ==========================================
# HARDWARE SPEC: RFID CARD READER (rfid_spec.txt)
# 硬體規格檔：RFID 刷卡感測器
# ==========================================

[DEVICE ATTRIBUTES / 設備屬性]
- Type: INPUT
- Device Code: "55"
- Default Pin Code: "0" to "4"

[BLOCK SCHEMA / 陣列結構 (Strict 7 Elements)]
["INPUT", "55", "<pin>", "=", "<card_id_string>", [<actions_array>], "N/A"]

[PARAMETER RULES / 參數規範]
- Position 0: "INPUT" (Fixed String)
- Position 1: "55" (Device Code for RFID Reader)
- Position 2: Pin Code ("0" to "4")
- Position 3: Operator (Fixed "=")
- Position 4: Card ID String (e.g., "CARD_1234", "CARD_A")
- Position 5: Actions Array (Nested list of hardware blocks to execute)
- Position 6: Default "N/A" (Required for 7-element array)

[EXAMPLES / 積木範例]
1. When Card "CARD_A" is scanned on P2, play Track 1 (當 P2 刷入卡號 CARD_A 時播放音樂 1):
   ["INPUT", "55", "2", "=", "CARD_A", [["OUTPUT", "2", "3", 80, 1, "N/A", "N/A"]], "N/A"]
