# ==========================================
# HARDWARE SPEC: SERVO MOTOR & FAN CONTROL (servo_spec.txt)
# 硬體規格檔：伺服馬達與風扇控制
# ==========================================

[DEVICE ATTRIBUTES / 設備屬性]
- Type: OUTPUT
- Device Code: "3"
- Default Pin Code: "0" to "4"

[BLOCK SCHEMA / 陣列結構 (Strict 7 Elements)]
- Angle Control Mode: ["OUTPUT", "3", "<pin>", "angle", <angle_0_360:number>, "N/A", "N/A"]
- Continuous Rotation Mode: ["OUTPUT", "3", "<pin>", "rotation", <speed_0_100:number>, "N/A", "N/A"]

[PARAMETER RULES / 參數規範]
- Position 0: "OUTPUT" (Fixed String)
- Position 1: "3" (Device Code for Servo/Fan)
- Position 2: Pin Code ("0" to "4")
- Position 3: Mode String ("angle" or "rotation")
- Position 4: Value (0 to 360 for angle mode, 0 to 100 for rotation speed)
- Position 5: Default "N/A"
- Position 6: Default "N/A" (Required for 7-element array)

[EXAMPLES / 積木範例]
1. Rotate Servo on P1 to 90 Degrees (將 P1 馬達旋轉至 90 度):
   ["OUTPUT", "3", "1", "angle", 90, "N/A", "N/A"]

2. Turn ON Fan on P1 at 100% Speed (將 P1 風扇轉速開至 100%):
   ["OUTPUT", "3", "1", "rotation", 100, "N/A", "N/A"]
