# ==========================================
# HARDWARE SPEC: AMBIENT TEMPERATURE SENSOR (temp_spec.txt)
# 硬體規格檔：環境溫度傳感器
# ==========================================

[DEVICE ATTRIBUTES / 設備屬性]
- Type: INPUT
- Device Code: "53"
- Default Pin Code: "0" to "4"

[BLOCK SCHEMA / 陣列結構 (Strict 7 Elements)]
["INPUT", "53", "<pin>", "<operator>", <celcius_value:number>, [<actions_array>], "N/A"]

[PARAMETER RULES / 參數規範]
- Position 0: "INPUT" (Fixed String)
- Position 1: "53" (Device Code for Temp Sensor)
- Position 2: Pin Code ("0" to "4")
- Position 3: Operator (">", ">=", "=", "<", "<=")
- Position 4: Celsius Temperature Value (Integer, e.g., 28, 30)
- Position 5: Actions Array (Nested list of hardware blocks to execute)
- Position 6: Default "N/A" (Required for 7-element array)

[EXAMPLES / 積木範例]
1. If temperature on P2 is greater than 30°C, turn ON Fan (當 P2 溫度 > 30°C 時開啟風扇):
   ["INPUT", "53", "2", ">", 30, [["OUTPUT", "3", "1", "rotation", 100, "N/A", "N/A"]], "N/A"]
