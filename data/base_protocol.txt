[STRICT ARRAY RULE / 嚴格陣列長度鐵律]
1. ALL hardware blocks MUST contain EXACTLY 7 elements in the JSON array (Index 0 to 6).
   所有積木指令在 JSON 陣列中【必須嚴格包含 7 個元素】（索引 0 至 6）。
2. Unused or optional parameters MUST be populated with default values: "N/A", "0", or [].
   未使用的參數【必須】填入預設值："N/A"、"0" 或空陣列 []。

--------------------------------------------
[DEFAULT PIN MAPPING / 預設腳位對照表]
--------------------------------------------
- P1 (Pin Code "1")
- P2 (Pin Code "2")
- P3 (Pin Code "3")
- P4 (Pin Code "4")

--------------------------------------------
[BLOCK SCHEMA DEFINITIONS / 積木結構定義]
--------------------------------------------

1. DELAY BLOCK (延遲積木)
   Schema: ["OUTPUT", "0", "0", "DELAY", <seconds:number>, "N/A", "N/A"]
   Example (Wait 2s): ["OUTPUT", "0", "0", "DELAY", 2, "N/A", "N/A"]

2. VARIABLE SET BLOCK (設定變數)
   Schema: ["VAR", "0", "0", "SET", "<var_name>", <value:number>, "N/A"]
   Example (Set TempWarning = 0): ["VAR", "0", "0", "SET", "TempWarning", 0, "N/A"]

3. VARIABLE MODIFY BLOCK (變數加減)
   Schema: ["VAR", "0", "0", "ADD", "<var_name>", <step:number>, "N/A"]
   Example (TempWarning + 1): ["VAR", "0", "0", "ADD", "TempWarning", 1, "N/A"]

4. VARIABLE READ BLOCK (讀取變數值)
   Schema: ["VAR", "0", "0", "STORE", "<var_name>", "N/A", "N/A"]
   Example (Get TempWarning value): ["VAR", "0", "0", "STORE", "TempWarning", "N/A", "N/A"]

5. IF LOGIC BLOCK (條件判斷積木)
   Schema: ["IF", <left_operand>, "<operator>", <right_operand>, [<action_blocks>], "N/A", "N/A"]
   Operators: ">", "<", ">=", "<=", "=="
   Example:
   [
     "IF",
     ["VAR", "0", "0", "STORE", "TempWarning", "N/A", "N/A"],
     ">",
     5,
     [
       ["OUTPUT", "0", "0", "DELAY", 1, "N/A", "N/A"]
     ],
     "N/A",
     "N/A"
   ]

--------------------------------------------
