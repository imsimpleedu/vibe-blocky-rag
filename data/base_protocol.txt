[STRICT ARRAY RULE / 嚴格陣列長度鐵律]
1. ALL hardware blocks MUST contain EXACTLY 7 elements in the JSON array (Index 0 to 6).
   所有積木指令在 JSON 陣列中【必須嚴格包含 7 個元素】（索引 0 至 6）。
2. Unused or optional parameters MUST be populated with default values: "N/A", "0", or [].
   未使用的參數【必須】填入預設值："N/A"、"0" 或空陣列 []。

-------------------------------------------------------------------------------
[BLOCK SCHEMA DEFINITIONS / 積木結構定義]
-------------------------------------------------------------------------------

1. DELAY BLOCK (延遲積木)
   Schema: ["OUTPUT", "0", "0", "DELAY", <seconds:number>, "N/A", "N/A"]

2. INPUT EVENT BLOCK (感測器觸發積木)
   Schema: ["INPUT", "<pin>", "<mode>", "<operator>", <value>, [<action_blocks>], "N/A"]
   Operators: ">", "<", ">=", "<=", "==", "!="

3. IF LOGIC BLOCK (條件判斷積木 - 僅限變數)
   Schema: ["IF", <left_operand>, "<operator>", <right_operand>, [<action_blocks>], "N/A", "N/A"]

-------------------------------------------------------------------------------
[LOGIC CONSTRUCTION RULES / 邏輯構建法則]
-------------------------------------------------------------------------------

1. DUAL-INPUT IF-ELSE PATTERN (雙重 INPUT 條件判斷)
   When query includes "if condition X, do A, else do B":
   - Generate TWO complementary INPUT blocks directly inside loop[].
   - Block 1 (Positive): Matching condition -> Action A nested in Position 5.
   - Block 2 (Negative): Inverse condition -> Action B nested in Position 5.
   CRITICAL: NEVER put an un-nested OUTPUT at the root of loop[] as an "else" fallback.
   CRITICAL: NEVER wrap an INPUT block inside an IF block.

2. EVENT-DRIVEN ACTION SCOPING (動作作用域)
   Triggered actions MUST strictly reside in Position 5 (action array) of the INPUT block.
   DO NOT place raw OUTPUT blocks before or after an INPUT block at the loop[] root level.

3. TIMED SEQUENTIAL EXECUTION (時序延遲控制)
   For multi-step actions (e.g. "Move to 150 deg for 4s, then 0 deg for 2s"):
   - Place movements sequentially in setup[] (run once) or loop[] (repeat).
   - EACH movement action MUST be directly followed by a DELAY block.

-------------------------------------------------------------------------------
[FEW-SHOT CANONICAL JSON EXAMPLES / 標準 JSON 生成範例]
-------------------------------------------------------------------------------

Example 1: Check card match 123456, if matched open red LED, if not close LED (RFID 比對：匹配開紅燈，不符關燈)
{
  "setupLoop": {
    "setup": [],
    "loop": [
      [
        "INPUT", "57", "0", "==", "123456",
        [["OUTPUT", "1", "1", 1, 30, "#ff0000", "N/A"]],
        "N/A"
      ],
      [
        "INPUT", "57", "0", "==", "",
        [["OUTPUT", "1", "1", 1, 30, "#000000", "N/A"]],
        "N/A"
      ]
    ]
  }
}

Example 2: Motor to 150 deg for 4s, then 0 deg for 2s (馬達轉 150 度維持 4 秒，再轉 0 度維持 2 秒)
{
  "setupLoop": {
    "setup": [],
    "loop": [
      ["OUTPUT", "3", "1", "angle", 150, "N/A", "N/A"],
      ["OUTPUT", "0", "0", "DELAY", 4, "N/A", "N/A"],
      ["OUTPUT", "3", "1", "angle", 0, "N/A", "N/A"],
      ["OUTPUT", "0", "0", "DELAY", 2, "N/A", "N/A"]
    ]
  }
}

Example 3: LED open red light for 1s, then close it for 3s (打開紅燈維持 1 秒，再關閉所有燈維持 3 秒)
{
    "setupLoop": {
        "setup": [],
        "loop": [
            ["OUTPUT", "1", "0", 1, 30, "#ff0000", "N/A"],
            ["OUTPUT", "0", "0", "DELAY", 1, "N/A", "N/A"],
            ["OUTPUT", "1", "0", 1, 30, "#000000", "N/A"],
            ["OUTPUT", "0", "0", "DELAY", 3, "N/A", "N/A"]
        ]
    }
}
